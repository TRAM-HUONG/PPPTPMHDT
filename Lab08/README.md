# Lab 08:Thuê Văn Phòng 

## 📁 Cấu trúc thư mục dự án

Dự án bao gồm các tệp tài nguyên và mã nguồn chính sau:

- **`Lab8.drawio`**: Sơ đồ thiết kế hệ thống / cơ sở dữ liệu (được vẽ bằng công cụ Draw.io).
- **`Lab8.sql`**: Tệp lệnh (script) cơ sở dữ liệu Microsoft SQL Server chứa các câu lệnh tạo bảng, ràng buộc hoặc dữ liệu mẫu.
- **`NguyenTramhuong.docx`**: Tài liệu báo cáo chi tiết nội dung của buổi thực hành Lab 8.
- **`Thuevanphong.zip`**: Tệp nén mã nguồn hoặc tài liệu tổng hợp của chương trình quản lý nhân sự.

## 🛠️ Hướng dẫn sử dụng

1. **Cơ sở dữ liệu (`Lab8.sql`)**: 
   * Mở Microsoft SQL Server Management Studio (SSMS).
   * Chạy tệp `Lab8.sql` để khởi tạo cơ sở dữ liệu cho hệ thống.
2. **Thiết kế hệ thống (`Lab8.drawio`)**: 
   * Mở bằng ứng dụng [Draw.io](https://app.diagrams.net/) hoặc tiện ích mở rộng trên VS Code để xem sơ đồ thiết kế.
3. **Báo cáo (`NguyenTramhuong.docx`)**: 
   * Mở bằng Microsoft Word để tham khảo nội dung chi tiết và kết quả thực hiện bài Lab.
