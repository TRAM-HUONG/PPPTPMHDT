# Bài Tập Lab 2 - Quản Lý Thư Viện

Thư mục này chứa các file bài tập, sơ đồ thiết kế và cơ sở dữ liệu cho dự án Quản Lý Thư Viện.

## Danh sách thư mục & tệp tin

* **PNG:** Thư mục chứa các hình ảnh sơ đồ đã xuất bản.
* **1250080066_HD_TT.drawio:** Sơ đồ Hướng hoạt động / Tuần tự (định dạng Draw.io).
* **1250080066_Usecase.drawio:** Sơ đồ Use Case (định dạng Draw.io).
* **1250088066_NguyenTramHuong_Lab2.docx:** Báo cáo chi tiết bài tập Lab 2 (file Word).
* **QuanLyThuVien.sql:** Script khởi tạo và truy vấn cơ sở dữ liệu SQL Server.
* **Lab2.rar:** File nén tổng hợp toàn bộ tài liệu dự án.

## Hướng dẫn sử dụng

1. **Mở sơ đồ (.drawio):** Truy cập [draw.io](https://app.diagrams.net/) hoặc cài đặt ứng dụng Draw.io Desktop để chỉnh sửa.
2. **Chạy Cơ sở dữ liệu (.sql):** Mở trực tiếp bằng Microsoft SQL Server Management Studio (SSMS) để thực thi script.
3. **Chạy Source Code:** Tải file ZIP code về, giải nén và mở/chạy dự án bằng Visual Studio.
