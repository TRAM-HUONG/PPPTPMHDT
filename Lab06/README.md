# Lab 06: Quản Lý Hồ Sơ Bệnh Nhân

## 📁 Cấu trúc thư mục dự án

Dự án bao gồm các tệp tài nguyên và mã nguồn chính sau

* **`Lab06 (1).drawio`**: Sơ đồ thiết kế hệ thống / cơ sở dữ liệu (được vẽ bằng công cụ Draw.io)
* **`Lab06.sql`**: Tệp lệnh (script) cơ sở dữ liệu Microsoft SQL Server chứa các câu lệnh tạo bảng, ràng buộc hoặc dữ liệu mẫu.
* **`NguyenTramhuong_Lab6.docx`**: Tài liệu báo cáo chi tiết nội dung của buổi thực hành Lab 6
* **`QuanLyHoSoBenhNhan.zip`**: Tệp nén mã nguồn hoặc tài liệu tổng hợp của chương trình quản lý hồ sơ bệnh nhân

## 🛠️ Hướng dẫn sử dụng

1. **Cơ sở dữ liệu (`Lab06.sql`)**: 
   * Mở Microsoft SQL Server Management Studio (SSMS).
   * Chạy tệp `Lab06.sql` để khởi tạo cơ sở dữ liệu cho hệ thống
2. **Thiết kế hệ thống (`Lab06 (1).drawio`)**: 
   * Mở bằng ứng dụng [Draw.io](https://app.diagrams.net/) hoặc tiện ích mở rộng trên VS Code để xem sơ đồ thiết kế
3. **Báo cáo (`NguyenTramhuong_Lab6.docx`)**: 
   * Mở bằng Microsoft Word để tham khảo nội dung chi tiết và kết quả thực hiện bài Lab
